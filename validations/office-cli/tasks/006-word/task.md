# 任务 006：Word CLI 功能验证任务定义

## 任务信息

| 项目 | 内容 |
|------|------|
| **任务 ID** | 006-word |
| **任务名称** | Word CLI 功能验证 |
| **优先级** | 高 |
| **验证对象** | OfficeCLI v1.0.143 — Word (.docx) 功能 |
| **前置条件** | OfficeCLI 已安装（见任务 001） |

## 任务目标

系统性验证 OfficeCLI 对 Word 文档 (.docx) 的读写编辑能力，评估其对人类 Word 操作的替代程度。

## 测试范围

### TC-001: 创建空白 Word 文档
- 创建空白 .docx 文件
- 验证文件创建成功且可用

### TC-002: 添加段落和文本
- 添加简单段落（纯文本）
- 添加多段落
- 验证段落内容正确

### TC-003: 文本格式（加粗、斜体、颜色、字号）
- 加粗文本
- 斜体文本
- 文本颜色
- 字体大小

### TC-004: 标题样式
- 使用内置标题样式（Heading 1/2/3）
- 验证样式应用

### TC-005: 段落对齐
- 左对齐、居中、右对齐
- 验证对齐方式

### TC-006: 表格
- 创建带数据的表格
- 验证表格行列数和内容

### TC-007: 列表
- 无序列表（bullet）
- 有序列表（ordered）

### TC-008: 超链接
- 添加超链接到文本
- 验证链接

### TC-009: 文档结构查看
- 使用 view outline 查看文档结构
- 使用 get 命令获取段落内容

## 测试数据文件

- 输出文件：`test-data/word-test.docx`

## 验证步骤

### 步骤 1：准备
```bash
officecli create test-data/word-test.docx
```

### 步骤 2：按顺序执行各测试用例
见上方"测试范围"中各 TC 的描述。

### 步骤 3：记录结果
- 每个测试用例的命令输出保存到 `results/evidence/006-word/`
- 最终结果写入 `tasks/006-word/results/result.md`
